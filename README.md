## 🚀 របៀបដំណើរការកូដ (How to Run VB.NET Code)

### វិធីទី ១៖ ប្រើប្រាស់ Visual Studio (ងាយស្រួលបំផុត)
1. បើក **Visual Studio (2019/2022)**
2. បង្កើតគម្រោងថ្មីជ្រើសរើស **Console App (Visual Basic)**
3. ចម្លងកូដពីឯកសារមេរៀននីមួយៗដាក់ចូលទៅក្នុង `Program.vb`
4. ចុច **F5** ឬ **Ctrl + F5** ដើម្បី Run

### វិធីទី ២៖ ប្រើប្រាស់ .NET CLI (Terminal / VS Code)
1. បើក Terminal ក្នុង Folder ណាមួយ
2. បង្កើត Project:
   ```powershell
   dotnet new console -lang "VB" -n "MyVBApp"
   ```
3. ចូលទៅកាន់ Folder:
   ```powershell
   cd MyVBApp
   ```
4. ដាក់កូដចូល `Program.vb` រួច Run:
   ```powershell
   dotnet run
   ```

### វិធីទី ៣៖ Compile ដោយផ្ទាល់តាមរយៈ `vbc.exe` (Command Prompt)
```cmd
vbc.exe /out:HelloWorld.exe 01_HelloWorld.vb
HelloWorld.exe
```

## 💡 គន្លឹះ និងច្បាប់ល្អៗក្នុង VB.NET (Best Practices)

> [!TIP]
> **១. តែងតែបើក `Option Explicit On` និង `Option Strict On`**  
> ជួយចាប់កំហុសប្រភេទ Type តាំងពីពេលសរសេរ (Compile-time) ការពារកុំឱ្យខុសទិន្នន័យពេលដំណើរការ។

> [!TIP]
> **២. ប្រើប្រាស់ `&` សម្រាប់ភ្ជាប់ String**  
> ជៀសវាងប្រើសញ្ញា `+` ព្រោះបើប៉ះលេខ វានឹងធ្វើប្រមាណវិធីបូកជំនួសឱ្យការភ្ជាប់អក្សរ។

> [!IMPORTANT]
> **៣. ប្រើប្រាស់ `Using` Statement លើធនធាន (Resources)**  
> ដូចជា `SqlConnection`, `StreamReader`, `StreamWriter` ដើម្បីឱ្យ .NET បិទ និងសម្អាត Memory ចោលដោយស្វ័យប្រវត្តិ។

> [!CAUTION]
> **៤. ហាមភ្ជាប់ SQL Query ដោយផ្ទាល់ (String Concatenation)**  
> ត្រូវប្រើ **Parameterized Queries (`cmd.Parameters.Add`)** ជានិច្ច ដើម្បីការពារការវាយប្រហារ **SQL Injection**។
